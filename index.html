Texts that don’t need translating

Texts that don’t need translating are left out of the counts and percentages. Texts with only numbers, symbols, placeholders, single characters or links are found automatically. Ctrl+Z and Ctrl+Y work here too.

Add language

Type a language name or code, for example French or fr. When you import the file, Unreal asks whether to add the language to your project.

Excel file

Translate in Excel, Google Sheets or LibreOffice, then import the file here. Each unique text is one row. Don’t change the first column: it’s used to find the texts again. Empty cells change nothing, and languages that aren’t in the file stay as they are.
